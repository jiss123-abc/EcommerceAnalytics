# Ecommerce SQL Analytics Project

## Project Overview
This project focuses on analyzing e-commerce data using Microsoft SQL Server. The objective is to explore customer behavior, sales performance, product performance, and business trends using SQL queries.

## Tools & Technologies
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- SQL

## Project Structure

```text

├── SQL/
```

## Project Phases

### Phase 1: Database and Table Creation
- Created database tables.
- Defined table structures.
- Established relationships between tables.

### Phase 2: Data Insertion
- Inserted data into the database.
- Populated the tables for analysis.

### Phase 3: Data Quality Checks
- Checked for NULL values.
- Identified duplicate records.
- Validated data consistency.

### Phase 4: Exploratory Data Analysis (EDA)
- Explored customer data.
- Analyzed orders and sales.
- Examined product performance.
- Investigated business trends.

### Phase 5: Advanced Business Analysis
- Performed advanced SQL analysis.
- Used joins and aggregate functions.
- Applied GROUP BY, ORDER BY, CASE WHEN, and subqueries where relevant.
- Extracted business insights from the data.

## Key SQL Concepts Used
- SELECT and WHERE
- JOINS
- GROUP BY and HAVING
- Aggregate Functions
- Subqueries
- Common Table Expressions (CTEs)
- CASE WHEN
- Window Functions
- Data Quality Checks

## How to Run the Project
1. Install Microsoft SQL Server and SQL Server Management Studio.
2. Clone or download this repository.
3. Open the SQL scripts in SSMS.
4. Execute the scripts in numerical order.
5. Explore the analysis queries and their results.
